# Security

Report a vulnerability privately through a
[security advisory](https://github.com/pedro-rodiguero/agent-cockpit/security/advisories/new), not in a
public issue. Fixes go to the latest release.

How the project tests its security (the to-do server's sign-in, scans in CI, what is not covered yet) is
in [docs/security.md](docs/security.md).
